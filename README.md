# DFIR Images Dataset

This repository provides forensic image samples designed for Digital Forensics and Incident Response (DFIR) training.

## Objectives
- Image metadata analysis
- EXIF examination
- Image authenticity verification
- Tampering detection
- Social media compression analysis

## Dataset Categories
- Original camera images
- Edited images
- Metadata modified images
- Social media processed images

## Tools Recommended
- ExifTool
- Autopsy
- FTK Imager
- Amped FIVE
- FotoForensics

## Disclaimer
All images are self-created for educational and research purposes only.
No real investigative or private data is included.
